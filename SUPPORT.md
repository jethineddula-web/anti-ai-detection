# Support

## How to get help

1. **Using the rules with an AI tool** — start with [README.md](./README.md) Quick start, then paste [`ANTI_SLOP.md`](./ANTI_SLOP.md) or a file from [`prompts/`](./prompts/).
2. **Bugs in docs or examples** — open a [Bug report](https://github.com/jethineddula-web/anti-ai-detection/issues/new?template=bug_report.md).
3. **New slop pattern** — open a [Pattern request](https://github.com/jethineddula-web/anti-ai-detection/issues/new?template=pattern_request.md).

## What this project is not

- Not a hosted product or SaaS
- Not an “AI detector” for text or images
- Not a full design system (use `tokens/` only as a starting example)

## Maintainer response

This is a small open catalog. Issues are reviewed as time allows; good reproductions and concrete rule proposals get priority.
