# Layout

## Banned structures (HIGH)

Do not default to these:

- Centered hero with a pill badge above the headline, a large centered title, a subhead, and two equally prominent CTAs (“Get Started” + “Learn More”)
- Exactly three identical feature cards in a row
- The skeleton: Hero → Features (3 cards) → Logo cloud → Pricing → FAQ → Footer regardless of content

## Why AIs default here

This is the highest-probability SaaS landing structure in training data. Models reproduce it when the prompt only says “landing page” or “modern marketing site.”

## Prefer instead

- Left-align hero copy when it improves scanning; make **one** CTA dominant
- Vary section structure: editorial splits, tables, timelines, single long-form block, asymmetric grids
- Order sections by the user’s job-to-be-done; skip logos/pricing/FAQ when they are empty or premature
- Use whitespace and type hierarchy before wrapping everything in cards

## Hero alternatives

- Split hero: copy left, product right (or reverse)
- Short top bar + dense product UI preview
- Typographic hero with one strong line and a single action
- Content-first: jump straight into the tool or doc

## Feature section alternatives

- Numbered list with outcomes, not icon cards
- Two-column compare
- One deep case study instead of three shallow cards
- Interactive demo or screenshots with captions

## Quick checks

- [ ] Not the dual equal-CTA centered hero by default
- [ ] Not forced three-up identical cards
- [ ] Section order is justified by content
- [ ] Each block answers: does this earn space for this product? If not, remove or rework it.
