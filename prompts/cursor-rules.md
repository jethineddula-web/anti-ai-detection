# Cursor Rules Example

Save as `.cursorrules` in the project root, or add to Cursor’s project rules.

```
You are generating UI code for this project. Follow these constraints.

NEVER:
- Use indigo/violet/purple accents or indigo→purple gradients
- Use Inter, Roboto, or Geist as the only font
- Gradient headline text
- Glassmorphism on normal cards
- Three identical feature cards with icon-in-rounded-square
- Centered hero with equal “Get Started” + “Learn More” CTAs as the default
- Soft shadow + oversized radius on every surface

ALWAYS:
- Prefer project design tokens when present
- One clear primary action per view
- Deliberate type pairing and accent outside the purple family when tokens are missing
- Hierarchy with spacing and typography before card chrome

When inventing visual style, make a specific choice and document it.
```
